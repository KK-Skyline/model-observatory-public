# 人话版更新日志

## 2026-11-06

这次给软件加上了抽样检查中转接口的能力。除了查看请求和回包里写的模型名，还能发送一组测试请求，把回答表现与参考样本比较，帮助发现换模型、降级或混用模型的线索。

### 可以怎么用

- 在看板里启动检查、看进度、取消任务和查看历史；Agent 也能通过命令行或接口使用同一套能力。
- 明确选择三种常见接口格式。参考样本不够、条件对不上或测试失败时，会显示“证据不足”。
- “模型名称声明是否一致”和“抽样表现是否异常”分开显示，避免把名称相同当成模型保真。

### 修好了什么

记录时间太久、选模未知或者关联证据不够时，会继续显示“待验证”；有明确依据说明没返回模型字段时，才显示缺失。两个界面的列表和历史都做了检查，超时和读取中断提示也保留。

损坏的历史以前可能留下没有检测依据的“未发现异常”，同一个任务写了两遍还可能悄悄覆盖一条。现在会明确报错，并完整保留原文件供追查。正常历史、失败、取消和标定记录仍能打开；运行到一半重启，也会明确记录中断失败。

### 这次验证到了哪里

候选版 211 项测试通过，独立审查发现的反例已修复并复验。公开仓库保留原有测试，加上本次新增测试共 202 项通过，两个界面的浏览器回归也通过。检查只用本机模拟接口，没有调用付费模型，也没有替换你正在使用的程序。新功能从独立入口启动。

“未发现异常”只代表这次抽样没有发现偏离，不能保证中转站每次都使用它声称的模型。真实服务、当前官方型号参考样本和实际费用仍需另外验证。
