# 其他客户端与上游来源：给 Agent 的接入指南

## 当前代码能做到什么

可以扩展，但不是即插即用。前端展示和精确模型比较可复用；目前读取层绑定 Codex SQLite、rollout/trace schema，以及采集器的 HTTP/WebSocket 协议。仅修改模型名称或上游地址不足以接入另一个客户端。模型服务商不同与客户端数据源不同也不是一回事。

实际接入点：

- `app.py:Scanner`：读取线程/项目、原生推理 start/terminal、选择快照，组装记录与诊断；当前选择取同线程同回合 `turn_context.model`。
- `rollout_sources.py`、`project_sources.py` 及 Scanner 中的归属逻辑：客户端会话文件发现、线程与项目归属；`monitoring_scope.py` 识别明确子智能体。其他客户端需提供自己的发现逻辑，不能伪造 Codex 数据库。
- `collector.py`：HTTP/WebSocket 转发和独立响应字段提取；安装路由在 `capture_control.py`，当前仅适配 Codex。不要用它修改其他客户端的配置。
- `connectivity.py`、`timeout_state.py`、`pending_diagnostics.py`：连接、超时和缺失证据解释。
- `static/app.js` 与 `design_preview/static/shell.js`：展示现有 Scanner 输出。保持字段合同，不在界面中猜测缺失证据。

## 推荐适配边界（尚未实现的设计）

先给新客户端实现只读适配器，提供线程/项目元数据、逐回合选择、逐请求发送模型、终态和独立响应声明，再在 Scanner 的读取入口接入。先做单来源隔离运行，验证后才考虑多来源合并；线程/回合/调用 ID 在跨来源合并时必须带来源命名空间，不能碰撞。

最少证据合同如下；这是适配器设计建议，不是当前已有的插件 API：

| 证据 | 必须保留 | 缺失时 |
| --- | --- | --- |
| 选择 | 同线程、同回合选择快照、模型原名、来源位置 | 待验证，不能用线程当前模型回填过去 |
| 请求 | 唯一调用 ID、线程/回合关联、发送模型原名 | 待验证并报告 |
| 完成 | 对应唯一终态、稳定响应 ID、完成/取消/失败区分 | 未完成不能伪装完成 |
| 上游 | 回包独立 model 字段、字段路径、稳定响应关联、完整性 | 待验证，不能复制请求模型 |
| 项目 | 可核对归属证据、冲突候选 | 项目待确认，不据此伪造模型不一致 |

仅凭时间邻近、文本相似或“最近一条请求”不构成权威关联；响应不提供独立 model 时必须如实待验证。响应声明也不证明内部权重。精确比较保留原名，不做静默别名归一化。

## 可直接交给下载者 Agent 的提示词

```text
请为我指定的新客户端/数据源添加只读适配器。
先询问客户端名称、版本、协议和可获得的脱敏schema样本；不要索要token或真实正文。
阅读 SOURCE_ADAPTER_GUIDE.md 及现有 Scanner、collector 和关联测试。
列出当前schema与目标schema的映射、稳定ID来源、独立响应model证据和缺失项。
先写适配设计，不要声称现有程序已支持任意来源。
保留前端、取消可逆筛选、模型原名精确比较和待验证规则。
在读取边界校验并统计坏行，不吞异常、不用默认值掩盖缺失。
优先新增来源适配器和合成fixture，不覆盖现有Codex解析器。
用合成样本验证：一致、不一致、缺选择、缺回包、重复ID、跨来源ID碰撞、
乱序、重试、取消无响应、部分响应、超时、连接中断和项目归属冲突。
无独立model或唯一稳定关联时保持待验证，不通过猜测提高验证率。
不自动安装拦截证书、不改系统代理、不发外部模型请求或转存真实正文。
若必须接入采集，先提出适配方案并取得对外请求/客户端配置修改授权。
新来源的存储维护必须有独立完成证明；不能复用Codex压缩规则假定已关闭。
完成后给出变更、实际测试、未验证边界和回退方式，并独立审查。
```

当前发布未实现通用 adapter 注册、其他客户端解析或多来源导入按钮。本指南供后续开发使用，不构成支持清单。
