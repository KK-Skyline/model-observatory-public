# 品牌图像提示词

## 当前选定：无发饰的人物头像

项目已选定银蓝短发、蓝眼睛、托腮思考的二次元人物。不要添加 O 形发饰、应用标志或任何头部装饰。前端侧栏使用48px头像，小屏44px，品牌副标题统一为 Model Observatory。原生应用使用同一人物的 `../model_monitor/native/AppIcon.icns`，包含16–1024px表示；构建时写入应用包并声明图标；启动时使用macOS渲染的应用包图标并显式请求512pt尺寸，保留系统圆角与高清表示，不把原始方形ICNS或默认32pt图标直接交给Dock。

README 顶部居中使用同一人物的 `assets/mascot.png`，显示尺寸180×180；标题、徽章和快捷导航紧随其后。PNG从前端已脱敏的头像资产中无损提取，只含IHDR、IDAT与IEND块，不带EXIF、文本或生成环境元数据。原来的合成界面插画保留在介绍正文。

```text
对附上的已选人物图做头像或横幅适配，保持同一张脸、银蓝短发、蓝眼睛、头部倾斜、托腮动作与海军蓝制服，不重新设计角色。
人物头发保持干净，不增加O形发饰、圆环、应用图标、蝴蝶结、耳机或其他装饰。
头像为1:1，头顶和左右留适量安全区，脸部与双眼在48至64像素缩略图中仍清晰；背景简洁浅冷蓝，不加文字、水印、边框或复杂HUD。
横幅为2:1，人物放右侧，左侧约45%留白供后期排版。延续同一人物与配色，不画假UI、真实数据或测试成绩。输出PNG。
```

下面保留早期抽象标志方案作为设计历史，已经弃用，不是当前人物的修改指令。

先生成方形标志，再把满意的标志作为参考图生成横幅。以下提示词为项目编写，可直接复制给图像模型；不依赖特定模型版本参数。

整理采用 gpt-image-2-style-library 的 **Brand Identity Package / 品牌身份包**（`brand-identity-package`，参考案例分类 case 354）；横幅沿用 **Brand Touchpoint Board / 品牌触点视觉板**（`brand-touchpoint-board`，case 362）的统一视觉原则。分类参考：https://github.com/freestylefly/awesome-gpt-image-2 。案例只作为风格分类依据，不复制案例标志或素材。

## 历史方案：抽象方形标志（已弃用）

```text
请为个人开源软件 Model Observatory（中文名“模型核对”）设计一枚原创图形标志。

【主体与任务】
这是一个在用户自己的 Mac 上追查“模型选择 → 发送请求 → 独立上游回包”的证据观测工具。核心气质是清晰、好奇、克制、可信。不要把它设计成聊天机器人或全知AI。
以三段等宽圆弧围成一个留有开口的抽象 O，中心放一个小圆点。三段弧线象征三段证据，中心点象征观测焦点。图形必须简洁且有自己的轮廓。

【构图与布局】
只输出一个正面、居中、独立的标志，占画布约65%，四周保留足够透明安全区。弧线和中心点在32像素缩略尺寸下仍可分辨，重心稳定，线宽一致。不要品牌展示板、不要拼贴多个方案、不要设备样机。

【风格与材质】
采用现代macOS软件气质、瑞士几何标志的清晰构成和光学校正。主色为冷静的钴蓝 #0A66E8，辅色仅用少量深海军蓝 #18324F。使用平面实色，边缘干净，保留可转绘为矢量的结构；这次不要玻璃高光、金属或3D挤出。

【文字要求】
品牌名仅用于理解，不要在画面中写任何文字、字母、数字、签名或水印。

【比例与输出】
1:1，优先2048×2048，PNG，真正透明背景，不是棋盘格图片。输出一张完整标志。

【约束】
必须原创，不复制Apple、OpenAI、GitHub或其他品牌标志。不画苹果、机器人、脑形、摄像头、监控眼睛、枪械瞄准镜、盾牌、勾号或复杂电路。不要霓虹、彩虹渐变、发光粒子、微小装饰和厚重阴影。不要声称已经验证了所有模型。
```

透明结果若不理想，可用纯白背景重新生成；不要让模型把棋盘格当成背景绘制。

## 历史方案：抽象标志横幅（已弃用）

```text
以我附上的标志为唯一品牌图形参考，为 Model Observatory（模型核对）制作一张横向GitHub README品牌插画。保持标志的几何结构、比例和钴蓝配色，不重新发明另一个标志。

【主体与任务】
表达“选择、请求和独立回包之间可追查的证据链”，是软件项目的品牌插画，不是产品实测截图。让三条克制的细线连接三个半透明几何节点，形成向右展开的观测路径；节点形状呼应标志的三段圆弧。

【构图与布局】
2:1横幅。左侧约45%保留干净留白，供后续人工排版；标志与抽象路径主要位于右侧。元素集中在中央安全区域，适合README缩小展示，不依赖细碎文字。画面保持完整，不加浏览器边框、设备模型或假UI。

【风格与材质】
浅冷灰白底 #F5F7FB，统一白色曲面，品牌钴蓝 #0A66E8 与少量深海军蓝 #18324F；只在几何层相互重叠处使用轻微磨砂玻璃质感。柔和侧光、很浅的接触阴影，干净、安静、有精度。不要紫色渐变、霓虹赛博、炫光或塑料玩具感。

【文字要求】
不要生成任何文字、数字、徽章、模型名称、状态标签、签名或水印。项目标题由后期排版加入，避免文字失真。不要绘制真实对话、用户名、文件路径或任何个人信息。

【比例与输出】
2:1，优先2400×1200，PNG，不透明背景。输出一张成品横幅，不要展示板或多图拼贴。

【约束】
不是监控产品，不画人眼或摄像头。不使用Apple/OpenAI/GitHub品牌标记。不模拟“全部验证通过”的数据，不虚构真实截图或测试成绩。延续参考标志，不套用通用AI大脑、电路和无限符号。
```

## 放入仓库前

检查缩略图辨识度、透明边缘、拼写、水印及PNG元数据；上传前移除非必要EXIF、文本和生成环境信息。这里的尺寸是期望规格，具体模型未必支持精确尺寸。当前README使用已选人物PNG作为项目形象，SVG合成界面插画仅用于介绍，不把生成图包装成实测截图。
